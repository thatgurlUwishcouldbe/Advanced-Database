# Lab 1 – Database Review

This lab was mainly a **review of the concepts and skills learned in the previous Database course**.

The lab provided an opportunity to refresh SQL fundamentals and practice working with relational databases through queries and data manipulation.

## Topics Covered

- Creating tables and defining relationships
- Primary and foreign keys
- SQL queries
- Data retrieval
- Aggregate functions
- Joins
- Subqueries
- Insert, Update, and Delete operations
- Working with relational data

## Exercises

### Exercise 1
Writing SQL queries using the University database schema.

### Exercise 2
Working with grades and grade points to calculate total grade points and GPA.

### Exercise 3
Practicing data manipulation through `INSERT`, `UPDATE`, and `DELETE` statements.

## Tools

- MySQL
- JDoodle
- SQL

## Purpose

The main purpose of this lab was to recover and reinforce previously learned database knowledge before progressing to more advanced database concepts.
